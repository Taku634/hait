# hait

ヘルスケア業界（IHH Healthcare等）に関する調査レポートを管理するリポジトリ。

## レポートの命名ルール

レポートをPushする際は、ファイル名を次の形式にする。

```
YYYYMMDD_<簡潔なレポート名>.md
```

- 冒頭に作成日を8桁（例: `20261022`）で付ける。
- 続けてアンダースコア、その後にできるだけ簡潔なレポート名（英小文字・ハイフン区切りを推奨）を付ける。
- 例: `20261022_ihh-sg-ceo-review.md`
